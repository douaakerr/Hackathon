# GUARDIAN

AI-powered medical cold-chain protection platform.

GUARDIAN helps pharmacies and healthcare facilities monitor medicine-storage conditions, identify risks early, and keep a clear history of temperature and power events.

## Current prototype

The frontend uses React, JavaScript, Vite, regular CSS, React Router, Recharts, and Lucide icons.

Dashboard readings are simulated for demonstration. No physical sensors or AI service are connected in this stage.

## Run the frontend locally

```bash
cd app
pnpm install
pnpm dev
```
